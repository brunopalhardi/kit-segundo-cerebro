Obsidian + Claude Code · método Karpathy

Seu segundo cérebro

Uma pasta de notas no seu computador que o Claude lê, organiza e alimenta com você. Você fala o que aprendeu ou decidiu; ele transforma em nota, liga às outras e guarda o histórico. O Obsidian é onde você lê e navega.

Como funciona

Três camadas de arquivos

raw/ Você joga

Material bruto como chegou: artigo, transcrição de reunião, anotação solta. Nunca é editado.

wiki/ O Claude escreve

Notas curtas, uma por assunto: livros, ideias, pessoas, projetos. Ligadas entre si.

index.md O mapa

O Claude lê o índice primeiro e abre só a nota que interessa. Assim o cérebro cresce sem ficar lento.

A ideia vem do Andrej Karpathy (ex-OpenAI e Tesla), que em 2025 propôs usar uma IA como bibliotecária de uma pasta de notas simples. Este kit soma a ela os ajustes que a fizeram funcionar no dia a dia.

Antes de começar

O que você precisa

  • Um Mac
  • Uns 20 minutos
  • Claude Code instalado e logado (plano pago do Claude)
  • Conta gratuita no GitHub, se quiser backup na nuvem
Instalação

Passo a passo

  1. Instale o Claude Code

    Siga as instruções em claude.com/claude-code. Para conferir, abra o app Terminal e digite claude. Se ele abrir e pedir login, está pronto.

  2. Baixe o kit

    Abra o link do kit que você recebeu, clique no botão verde Code → Download ZIP e dê dois cliques no arquivo baixado para descompactar. Ele vira uma pasta nos seus Downloads.

  3. Abra o Claude dentro da pasta do kit

    No Terminal, cole:

    cd ~/Downloads/kit-segundo-cerebro-main
claude

    Se o nome da pasta for outro, digite cd com espaço e arraste a pasta para dentro do Terminal.

  4. Peça a instalação

    Instala meu segundo cérebro seguindo o INSTALAR.md

    O Claude faz 5 perguntas, uma por vez: seu nome, seu trabalho e projetos, o que nunca pode entrar no cérebro, onde criar a pasta e se você quer backup no GitHub. Depois cria tudo sozinho.

    Quando ele pedir permissão para rodar um comando, leia o que é e aprove.

  5. Abra o cérebro no Obsidian

    Instale o Obsidian, clique em Abrir pasta como cofre e escolha a pasta que o Claude criou. Depois, em Configurações → Plugins da comunidade, ative os plugins, procure Git (autor Vinzent), instale e ative. A configuração já vem pronta: ele salva uma versão a cada 10 minutos.

  6. Faça o primeiro registro

    Ainda na conversa com o Claude, diga algo real do seu trabalho:

    salva no cerebro: decidi que ...  (e o porquê)

    A nota aparece no Obsidian em segundos. Pronto, está funcionando.

No dia a dia

Por que funciona

As quatro regras do método

Grava direto e avisa

Quando o Claude percebe algo que vale guardar, ele grava na hora e avisa numa linha que começa com 📌. Se não quiser aquela nota, peça para tirar. Perguntar antes "quer que eu salve?" fazia quase nada ser salvo: num caso real, 22 sugestões viraram 1 nota.

Sigilo definido por você

Na instalação você diz o que nunca pode entrar (faturamento de cliente, dados de paciente, contratos). Senhas e documentos de terceiros ficam fora sempre. Na dúvida, o Claude pergunta antes de gravar.

Problema resolvido, nota atualizada

Quando algo que estava pendente é resolvido, a nota ganha o estado novo com data. O cérebro descreve o presente, não o passado.

Cada projeto sabe onde parou

Todo projeto tem uma seção "Estado atual" com o feito, o pendente e o próximo passo. É o que permite fechar a conversa hoje e retomar amanhã com uma frase.

Dúvidas

Perguntas comuns

Para onde vão minhas notas?

Os arquivos ficam no seu computador, e no seu GitHub privado se você escolheu backup. O que o Claude lê para responder passa pelos servidores da Anthropic, como qualquer conversa com ele. Por isso a regra de sigilo existe.

O Claude gravou uma nota que eu não queria

Diga "tira essa nota". Ela vai para a pasta de arquivo e sai do índice. O histórico guarda tudo, então nada se perde de vez.

Preciso abrir o Obsidian para usar?

Não. O Claude trabalha direto nos arquivos. O Obsidian serve para você ler, navegar e ver o gráfico de ligações entre as ideias.

Funciona no Windows?

O kit foi feito e testado no Mac. No Windows, com o Claude Code e o Git instalados, deve funcionar, mas ainda não foi testado.

Uso o Codex também

As regras do cérebro ficam no arquivo AGENTS.md, que o Codex lê. Se você tem o Codex instalado, a instalação também avisa a ele onde fica o seu cérebro.

Quero mudar uma regra

Peça ao Claude: "muda a regra do cérebro para …". Ele edita o AGENTS.md da pasta do cérebro, que é onde todas as regras moram.
