## No dia a dia

| Diga ao Claude | O que acontece |
|---|---|
| `salva no cerebro: <ideia, decisão, aprendizado>` | Vira nota, entra no índice e fica salva |
| `ingere isso` (colando um texto, transcrição ou artigo) | O material bruto vira nota resumida e ligada às outras |
| `busca no cerebro: <tema>` | Responde com base nas suas notas |
| `consolida` | Arruma o índice com o que entrou recentemente |
| `bora continuar <projeto>` | Retoma o projeto de onde parou |

O Claude também grava sozinho o que perceber que vale guardar, e avisa numa linha começando com 📌.
Se não quiser aquela nota, é só pedir para tirar.
